Windows: Windows SmartScreen may show a warning. This is expected: choose More info → Run anyway to continue. ProjBox runs entirely on your computer, with no account, cloud, or uploads.

macOS: This early-access build is not yet notarized, so macOS may show a security warning on first launch. If blocked, go to System Settings → Privacy & Security → Open Anyway.

After you install

  1. After installing, choose a project folder you already work in and click Run Snapshot to save its first version. You’ll now notice a new _ProjBox_History folder inside your folder. That’s where ProjBox keeps your saved versions.
  2. Keep working normally—adding, deleting, or renaming files, editing Excel files, etc.
  3. Run another snapshot to see an elegant summary of what changed in your folder.
  4. Double click individual files in the summary to see differences in each file since your previous snapshot. This will be your “Eureka” moment.
